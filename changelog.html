v0.2.0

September 18, 2026
  • Preview URLs are now created for every branch, not just the default one, and are posted back to the pull request as soon as the build is green.
  • Build and deploy logs stream into the same view, so a failing deploy no longer sends you hunting through two tabs.
  • Fixed a race where a second push while a build was running could leave the older commit marked as deployed.

v0.1.0

August 27, 2026
  • First public release: describe a change in the prompt bar and get a draft pull request with the diff.
  • Merges are blocked while checks are running or failing.
